HTML Offline Documentation

A lightweight offline reference for HTML tags & attributes

HTML Reference

<!DOCTYPE> <html> <head> <body> <title> <meta> <h1> – <h6> <p> <a> <img> <div> <span> <ul>, <ol>, <li> <table> <form> <input> <video> <audio> <code>, <pre>

<!DOCTYPE>

Specifies the HTML version used in the document.

<!DOCTYPE html>

<html>

Root element of an HTML page.

<html lang="en">
...
</html>

<head>

Contains metadata, styles, and scripts.

<head>
    <meta charset="UTF-8">
    <title>Document</title>
</head>

<body>

Main visible content of the page.

<body>
    Hello World!
</body>

<a>

Creates a hyperlink.

<a href="https://example.com">Click here</a>

<img>

Embeds an image.

<img src="image.jpg" alt="description">

<form>

Creates an input form.

<form action="/submit" method="post">
    <input type="text" name="fullname">
</form>

<video>

Embeds a video.

<video controls>
    <source src="movie.mp4" type="video/mp4">
</video>

<audio>

Embeds audio.

<audio controls>
    <source src="sound.mp3" type="audio/mpeg">
</audio>
